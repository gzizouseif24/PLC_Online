# Session summary: 2026-10-30

## Done today (TSX Micro, tested on the bench TSX 3721)

| Feature | Command | How we got it |
|---|---|---|
| Data backup | `sauvegarder-donnees` → CSV of all %MW / %KW | reads each zone until the PLC refuses (found 512 / 128) |
| Data restore | `restaurer-donnees FILE` | writes only changed %MW, blocks of up to 60, then reads back |
| Program restore | `restaurer FILE.tsxbak` | sequence from a Portmon capture of PL7's PC → PLC transfer |
| Program compare | `comparer FILE.tsxbak` | confirmed identical after a restore |

`restaurer` backs up the current program first (`avant_restauration_*.tsxbak`), sets STOP,
sends the program in 122-byte segments, and reads it back to check.

Also learned:
- `.FEF` (PL7 export) is readable text: configuration + program. PL7 can import it
  (new empty application → Fichier → Importer une application). Loading a `.FEF` without PL7
  is not realistic (needs PL7's compiler); a `.tsxbak` can be restored without PL7.
- PL7's animation table uses its own requests (`91`, `92`, `93`). Not needed for our watch
  tables, which read values directly.
- READ_CPU (`4F`) answer changes with RUN / STOP / transfer: could give the PLC state.

## Omron CJ1M (afternoon, bench CJ1M-CPU11 + CJ1W-ID211 + CJ1W-OC211)

`tools/omron.py` now does what `tsx.py` does, except program restore.

| Feature | Command | Bench |
|---|---|---|
| Status, faults, battery, clock, I/O cards with live CIO | `etat` | yes |
| Error log | `erreurs` | yes (empty log) |
| PLC Setup and registered I/O table | `parametres` | yes |
| Read D, CIO, H, A (C-mode) and W, T, D10000+ (FINS) | `lire` | yes |
| Watch bits | `surveiller` | ran; inputs to try with the ID211 |
| Mode | `run` / `monitor` / `programme` | MONITOR yes |
| Write one word | `ecrire` | yes, in MONITOR |
| Data backup | `sauvegarder-donnees` | yes: D 336 s, H 4 s, W 5 s |
| Data restore | `restaurer-donnees` | to redo (first run looked frozen: progress added) |
| Program backup / compare | `sauvegarder` / `comparer` | backup yes (19,264 bytes, 53 s) |

How we got there:
1. Omron manuals instead of sniffing: **W342** (communication commands) and **W393** (CJ1M
   operation). Fixed several wrong guesses before the bench: status bits, error log reply,
   program read alignment and size.
2. Bench: FINS works through the peripheral port. The reply has a `00` end code after `FA`,
   which the W342 diagram leaves out (seen with `--trace`).
3. I/O table format (not in the manuals) decoded by comparing with CX-Programmer's I/O table
   window: one word per slot, `0402` = ID211 (CIO 0), `0450` = OC211 (CIO 1).
4. Repo reorganised: `tools/` (what you run), `plc_online/protocols/` (library), `research/`.

Found on the bench PLC: no battery and battery detection off in the PLC Setup, so the clock
is wrong (04/02/2022) and D/H can be lost at power off.
