## TSX: what works now (`tsx.py`, without PL7)

| Command | What it does | Tested on the bench |

## TSX: how we got there

1. Listened to the TER port: 9600 baud, odd parity, PLC polls slaves 1–8.
2. Mirror test from the PC: link confirmed (PC = slave 1, PLC = station 0xFE).
3. Probes: found %S (V1 `01`), %SW (segment 6A), %MW (segment 68), write (`37`), RUN (`24`).
4. PL7 help files (`.hlp`, decoded with `tools/hlp2txt.py`): official list of UNI-TE requests.
5. Your proxy capture of PL7: the full program upload sequence → `sauvegarder`.
6. `.FEF` export: readable text of the application (configuration + program).

Bugs found on the bench and fixed: stale polls answered out of turn; slow poll cycle
(the PC now answers EOT like PL7).
