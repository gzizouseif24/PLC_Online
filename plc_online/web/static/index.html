Connexion

S7-300 : STEP 7 installe, interface PG/PC sur USB.S7USB.1, SIMATIC Manager ferme.

TSX : cable TSX PCX 1031 sur la prise TER, selecteur dans la meme position qu'avec PL7, PL7 ferme. 9600 bauds, 8 bits, parite impaire.

Delta : adaptateur RS-485 sur COM2 (+ / -) ou cable RS-232 sur COM1 (mini-DIN), WPLSoft / ISPSoft ferme. Defaut Delta : ASCII 9600 7E1, station 1. Reglages inconnus : bouton Chercher les reglages ; IHM branchee sur le RS-485 : Ecouter l'IHM.

Panasonic : cable USB / RS-232 sur le port outil (mini-DIN 5), FPWIN ferme. Defaut du port outil : 9600 bauds, 8 bits, parite impaire (O), station 1. RUN / PROG a distance : selecteur de l'automate sur RUN.

Mitsubishi FX : cable SC-09 / USB-SC09 sur le port de programmation (mini-DIN 8 sous le capot), GX Developer / GX Works ferme. 9600 bauds 7E1. Renseigner l'unite de base et les extensions dans l'ordre (le FX ne les signale pas).

Omron : cable CS1W-CN226 / USB-serie sur le port peripherique, CX-Programmer ferme. Port en Host Link 9600 7E2, unite 0 (DIP 4 ON). En RUN l'automate refuse les ecritures : passer en MONITOR.

Allen-Bradley : cable Ethernet sur le reseau de l'automate (port de la CPU ou module 1756-EN2T), PC dans le meme reseau. Emplacement CPU : 0 en general. Necessite pip install pycomm3.

WAGO : cable Ethernet entre le PC et le coupleur, puis Recherche automatique.
